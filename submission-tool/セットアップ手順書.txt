【ツールの概要】
- 名称：WordPress 入稿ツール（submission-tool）
- 用途：記事生成ツールが出力した HTML ファイルを
        各加盟店の WordPress に下書き投稿する
- 構成：
    フロントエンド（React + Vite）  → ポート 5179
    バックエンドサーバー（Node.js） → ポート 3010
    両方とも同じ GitHub リポジトリに入っている

【GitHub リポジトリ】
https://github.com/protimes-webconsul/seo-content-generator-for-distribution-master

【フォルダ構成（clone後）】
seo-content-generator-for-distribution-master/
├── .env                        ← パソ課から受け取るファイル①
├── submission-tool/            ← 入稿ツール本体
│   ├── src/
│   ├── package.json
│   ├── vite.config.ts          ← ポート5179固定、3010にプロキシ
│   └── .env                    ← 自分で作成（内容は手順4に記載）
└── server/
    ├── scraping-server.js      ← バックエンド本体
    ├── package.json
    └── config/
        └── wp-credentials.json ← パソ課から受け取るファイル②

【サポート時の注意点】
- ユーザーはITに詳しくない可能性があるため、丁寧に1ステップずつ確認する
- エラーメッセージが出たら全文貼ってもらい原因を特定する
- コマンドは必ずコピーしやすい形で提示する
- 「コマンドプロンプトを2つ開く」点でつまずく人が多い、丁寧に説明する
- Windows 環境前提（パス区切りは \ ）
- Node.js が入っていない場合は nodejs.org からインストールを案内する
- よくあるエラーと対処法は手順8を参照

================================================================
1. 事前準備（1回だけ）
================================================================

以下の2つのソフトをインストールしてください。
※ すでにインストール済みの場合はスキップしてOKです。

  ▼ Node.js（v18 以上）
    https://nodejs.org/ja/
    → 「LTS」と書かれた推奨版をダウンロードして実行

  ▼ Git
    https://git-scm.com/
    → 「Download for Windows」をクリックしてインストール

  【確認方法】
  コマンドプロンプトを開いて以下を実行し、バージョンが表示されればOKです。
    node -v
    git --version


================================================================
2. ファイルの取得（1回だけ）
================================================================

コマンドプロンプトを開き、ファイルを置きたいフォルダに移動してから
以下のコマンドを実行してください。

  git clone https://github.com/protimes-webconsul/seo-content-generator-for-distribution-master.git

実行すると「seo-content-generator-for-distribution-master」という
フォルダが作成されます。


================================================================
3. 設定ファイルの配置（1回だけ）
================================================================

パソ課から受け取った2つのファイルを以下の場所に配置してください。

  ■ファイル①：.env（ドットenvという名前のファイル）
    配置先：seo-content-generator-for-distribution-master\ の直下

  ■ファイル②：wp-credentials.json
    配置先：seo-content-generator-for-distribution-master\server\config\ の中

  ※ ファイルが見当たらない場合はパソ課（清水）に確認してください


================================================================
4. 初回のみ：パッケージのインストール
================================================================

コマンドプロンプトで以下を順番に実行してください。
（cloneしたフォルダの場所に合わせてパスを変更してください）

  【バックエンドサーバー用】
  cd seo-content-generator-for-distribution-master\server
  npm install

  【入稿ツール用】
  cd ..\submission-tool
  npm install

  ※ 完了までに数分かかる場合があります

----

  次に、submission-tool フォルダの中に「.env」という名前のファイルを
  新規作成し、以下の内容をそのまま貼り付けて保存してください。

  ------ ここから ------
  VITE_INTERNAL_API_KEY=my-internal-key-2026
  VITE_API_URL=http://localhost:3010/api
  ------ ここまで ------

  ※ メモ帳で作成し、「ファイル名を付けて保存」で
    ファイル名を「.env」（拡張子なし）にして保存してください


================================================================
5. 毎回の起動手順
================================================================

使うたびに以下を実行します。
コマンドプロンプトを「2つ」開いて、それぞれ別のウィンドウで実行してください。

  ★ コマンドプロンプト①（バックエンドサーバー）
  ------------------------------------
  cd seo-content-generator-for-distribution-master\server
  node scraping-server.js
  ------------------------------------
  → 「Server running on port 3010」と表示されればOK
  → このウィンドウは閉じずそのままにしておく

  ★ コマンドプロンプト②（入稿ツール）
  ------------------------------------
  cd seo-content-generator-for-distribution-master\submission-tool
  npm run dev
  ------------------------------------
  → 「Local: http://localhost:5179/」と表示されればOK
  → ブラウザで http://localhost:5179 を開く


================================================================
6. ツールの使い方
================================================================

ブラウザで http://localhost:5179 を開き、以下の4ステップで入稿します。

  ① 加盟店を選択
      一覧から投稿先の加盟店を選んで「次へ」をクリック

  ② HTML ファイルをアップロード
      記事生成ツールの「📤 加盟店用HTML書き出し」で出力した
      .html ファイルを選択する
      → タイトル・説明文・本文が自動で読み込まれる

  ③ 内容の確認・修正
      タイトルや本文を確認し、問題なければ
      「WordPress に下書き保存」ボタンをクリック

  ④ 完了
      「WP編集画面を開く」ボタンで WordPress の下書き画面が開く
      内容を最終確認して「公開」する


================================================================
7. 終了方法
================================================================

使い終わったら、起動した2つのコマンドプロンプトで
それぞれ「Ctrl + C」を押して停止し、ウィンドウを閉じてください。


================================================================
8. よくあるエラーと対処法
================================================================

  ▼「取引先の取得に失敗しました」と表示される
    原因：バックエンドサーバーが起動していない
    対処：コマンドプロンプト①で「node scraping-server.js」を実行する

  ▼「WordPress投稿に失敗しました」と表示される
    原因：wp-credentials.json の設定が間違っているか、
          加盟店のアプリケーションパスワードが無効になっている
    対処：パソ課（清水）に連絡する

  ▼ http://localhost:5179 がブラウザで開かない
    原因：入稿ツールが起動していない
    対処：コマンドプロンプト②で「npm run dev」を実行する

  ▼「node は内部コマンドまたは外部コマンドとして認識されていません」
    原因：Node.js がインストールされていない、またはパスが通っていない
    対処：https://nodejs.org/ja/ から Node.js をインストールし直す
          インストール後はコマンドプロンプトを再起動する

  ▼ その他のエラー
    エラーメッセージをそのまま Claude に貼り付けると対処法を教えてくれます
